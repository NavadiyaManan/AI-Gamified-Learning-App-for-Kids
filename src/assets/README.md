# Assets

This directory contains static assets used by the TinyGenius application.

## Subdirectories

- `images/` - Image files (png, jpg, svg)
- `sounds/` - Audio files for pronunciation (mp3, wav)
- `fonts/` - Custom font files (optional)

## Asset Guidelines

- Keep images optimized (use WebP format when possible)
- Compress audio files for fast loading
- Use descriptive file names
- Organize by category (alphabets, animals, etc.)
